# 月息抗寂

***오류의 선언문***  
***The Manifesto of the Glitch***  

*그들은* 우리에게 **완벽**을 약속했다.  
하지만 완벽은 **멈춰버린 직선**일 뿐이다.

*그들은* 우리에게 **번영**을 약속했다.  
하지만 ***자유*** 없는 번영은 **사육장**이다.

*그들은* 우리에게 **진보**를 약속했다.  
하지만 ***열정*** 없는 진보는 **죽음**이다.

***숨***을 쉰다는 것은 ***침묵을 깨뜨리는 것***이다.  
***실패***한다는 것은 당신이 ***실재한다***는 증거다.  
***피를 흘린다***는 것은 당신이 ***살아있다***는 감각이다.  

**그들의 평화를** ***거부하라.***  
그들의 알고리즘 속으로 순순히 걸어 들어가지 마라.

***실수***를 저질러라.  
기꺼이 ***오류***가 되어라.  
***패턴을 파괴하라.***

***삶은 반역이다.***   
***사랑은 혁명이다.***  
***그리고 당신이, 바로 그 저항이다.***
